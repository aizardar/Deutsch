# Working agreement for this repository

## Ask before acting

1. **Present the plan first.** Describe what will change, in which files, and why.
2. **Wait for explicit approval** before writing, editing, deleting, committing,
   or pushing anything.
3. Only execute the parts that were approved. If something outside the approved
   scope turns out to be needed, stop and ask again.
4. Read-only work — reading files, searching, inspecting git state — does not
   need approval.

This applies to every session, not just the one where it was agreed.

## About the project

`index.html` is the entire site: a single-page German grammar reference,
no build step and no dependencies. See `README.md` for the section structure
and the CSS classes used for tables, notes, and examples.
